# Citation, license, and contact

## Citation

If you use OpenPDAC in scientific work, cite the software using the metadata in
the repository's
[`CITATION.cff`](https://github.com/demichie/OpenPDAC-14/blob/main/CITATION.cff).
GitHub also presents these metadata through **Cite this repository**.

When appropriate, cite the publications describing the physical and numerical
formulations used by the selected model and tutorial.

!!! warning
    Before publishing this documentation, update `CITATION.cff`: the current
    file still contains repository and version metadata inherited from earlier
    OpenPDAC releases.
